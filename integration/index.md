# 集成总览

把 Schema Platform 的核心业务能力接入你现有的系统。

## 你可以接入什么

| 能力 | 适合场景 | 文档 |
|---|---|---|
| 工作流 API | 外部系统触发一个已发布的智能体工作流 | [工作流 API](./workflow-api.md) |
| 页面嵌入 | 把已发布的业务表单或页面嵌到你的系统 | [页面嵌入](./embed-pages.md) |
| MCP 工具 | 让模型调用你的内部工具或数据源 | [MCP 工具](./mcp.md) |
| API Key | 用密钥代替人工登录调用接口 | [认证方式](./authentication.md) |

## 推荐路径

1. 先确认你要接入的是**业务表单 / 页面**还是**智能体工作流**。
2. 如果是页面，看 [页面嵌入](./embed-pages.md)。
3. 如果是工作流，看 [认证方式](./authentication.md) 和 [工作流 API](./workflow-api.md)。
4. 如果你要让模型调用内部系统，看 [MCP 工具](./mcp.md)。

## 常见问题

**我需要自己写 SDK 吗？**

不需要。平台的开放能力基于标准 HTTP，直接用 `fetch`、`axios`、`curl` 或你熟悉的 HTTP 客户端即可。

**可以用回调代替轮询吗？**

可以。触发工作流时传入回调地址，执行完成后平台会主动通知你的系统。
