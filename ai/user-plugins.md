# 扩展能力（插件）— 用户指南

> 本文面向**使用者与租户管理员**。说明如何在平台里使用「专家 / 技能 / 工具 / 外部工具服务」，不涉及前端内部实现细节。

---

## 你能做什么

| 能力 | 你在界面上看到的 | 用途 |
|------|------------------|------|
| **专家** | 插件中心 · 专家；对话自动路由；工作流「专家」节点 | 表单 / 流程 / 页面等专业助手 |
| **技能** | 插件中心 · 技能 | 附加到专家的写作与质量规范 |
| **工具** | 插件中心 · 工具；工作流「工具」节点 | 查表单、改流程、检索知识库等动作 |
| **工具服务** | 设置 · 工具服务 | 连接外部工具服务端，供工具调用 |

对话与工作流**共用**同一套已启用能力：在对话里能用的专家/工具，在工作流里也可以编排。

---

## 常见操作

### 查看已启用能力

1. 打开 AI 应用 → 设置 → **插件中心**  
2. 切换「专家 / 工具 / 工具服务 / 技能」查看当前租户可用项  

### 在对话中使用

- 默认「智能对话」会按你的问题自动选择专家  
- 也可在对话设置中绑定**已发布工作流**，改为按流程图执行  

### 在工作流中使用

1. 打开 **工作流** → 新建或编辑  
2. 从左侧拖入「专家」或「工具」节点  
3. 在右侧属性中选择具体专家或工具  

### 自建专家 / 工具（运维）

由平台或租户运维在服务端配置目录或插件包中注册，热加载后出现在插件中心。  
第三方开发步骤见：[第三方插件指南](./extend/third-party-plugin-guide.md)（面向扩展开发者）。

---

## 与「我的模型」的关系

- **普通用户**：需在设置中添加**自己的**大模型 API Key，才能对话 / 跑工作流（不使用服务器环境变量里的平台 Key）。  
- **管理员**：可使用平台配置的模型；同时建议绑定信任设备（见安全说明）。  

详见：[账号与安全](./user-security.md)。
