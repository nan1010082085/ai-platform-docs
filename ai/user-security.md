# 账号、权限与安全 — 用户指南

> 面向最终用户与租户管理员。说明登录之外的权限、自有模型与管理员设备保护。

---

## 1. 两种接入方式

| 方式 | 谁用 | 说明 |
|------|------|------|
| **登录（人机）** | 你在浏览器使用 UA / AI / 编辑器 | 账号密码 + 会话；管理员可叠加设备绑定 |
| **API Key（机器）** | 外部系统、脚本调工作流 | 用户平台 Key（`X-API-Key`）或工作流 Key（`X-Workflow-Key`）；见 [SDK 指南](./sdk.md) |

日常使用只需登录。机器对接请使用集成密钥，或联系管理员开通权限。

---

## 2. 角色与权限（UA）

在 **用户管理台（UA）** 可管理：

- 用户、角色、租户  
- 角色上的权限码（如「AI 对话」「自有模型」「工作流」）  

**普通用户**默认可以：对话、工作流、管理自己的 API Key 与**自有模型**。  
**管理员**额外可以：管理租户级模型、用户与角色等。

若某菜单提示无权限，请联系管理员在 UA → 角色中勾选对应权限。

---

## 3. 自有模型（非管理员必做）

普通用户**不会**自动使用服务器上的平台 API Key。

1. 登录 AI 应用 → 设置 → **模型中心** →「个人 API Key」  
2. 添加供应商、模型名与 API Key  
3. 设为默认后即可对话 / 执行工作流  

密钥加密存储；列表中仅显示脱敏。丢失后请重新填写。

管理员仍可使用平台 / 租户配置的模型；也可为自己添加自有模型。

---

## 4. 管理员：绑定本机并防异常访问

为降低盗用风险，管理员应：

1. 在本机（如 Mac）完成**设备绑定**（信任设备）  
2. 之后敏感操作携带本机设备标识  

若系统发现**未知设备或异常登录**，会对该管理员账号实施**临时封禁**（默认约 24 小时）。  
因异常访问通常不是本人操作，请：

- 使用已绑定的信任设备，或联系另一管理员解封  
- 轮换密码与 API Key  

设备列表可在绑定接口 / UA「我的设备」页查看；吊销丢失设备。
