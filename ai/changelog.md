# AI 平台 · 更新日志

> 记录 AI 平台（对话智能体 / 智能体工作流 / 知识库 / 插件中心）的主要功能更新。

## 2026-09-05 · 租户登录接线 + BYOK/限额文档关单

- **登录**：AI 锁定 `tenantCode=chat`；模型中心展示有效额度提示
- **BYOK**：个人 API Key 区（`PersonalLlmSection`）；非管理员禁止回落平台 Key（文档关单见设计）
- **开放**：知识库 UX、合流面板、服务双因子、P7 邮件 — [open-work-inventory](../design/open-work-inventory.md)

## 2026-07-27 · 多智能体与长程记忆

- **Memory 节点**：工作流支持长程记忆节点，跨会话上下文持久化
- **Agent Handoff**：多专家间任务交接，显式 handoff 协议
- **并行执行**：`parallel` 节点支持多分支并行 + 汇聚
- **Agentic RAG**：检索增强从被动引用升级为主动检索决策

## 2026-07-24 · 全链路与提示词优化

- **全链路架构**：Chat → LangGraph → LLM → 行业模板完整链路
- **LangGraph 优化**：状态管理、节点复用、错误恢复等稳定性提升
- **提示词优化**：温度策略 + 提示词规范，输出更稳定
- **行业模板扩充**：覆盖 HR / 财务 / 运营 / 客服 / 法务等分类

## 2026-07-22 · 智能体深化与 Workflow-as-Agent

- **子 Workflow 调用**：工作流节点可调用已发布的子工作流
- **成本可见与配额**：执行成本统计、租户配额管理
- **agent-loop 节点**：工作流支持自主循环决策
- **Workflow 作技能**：已发布 workflow 可作为 Agent 技能被调用
- **复杂文件组件化**：大文件拆分，首屏性能优化

## 2026-07-15 · 插件中心完善

- **插件热重载**：HUP 信号触发热重载，无需重启服务
- **技能拼装规范**：技能组装技术规范
- **打包规范 v1**：插件打包规范 v1
- **第三方插件指南**：外部开发者接入文档

## 2026-07-10 · RAG 知识库

- **BGE-M3 embedding**：向量化模型接入
- **BGE-Reranker 重排**：检索结果重排序
- **混合加权融合**：向量检索 + 关键词检索加权融合
- **文档分块策略**：智能分块、重叠窗口

## 2026-07-05 · 智能体工作流引擎

- **DAG 工作流编排**：多节点类型可视化编排
- **BullMQ 执行引擎**：持久化队列 + 自动重试 + 死信队列
- **节点执行监控**：实时进度推送（WebSocket）
- **子工作流调用**：支持嵌套工作流

## 2026-06-30 · AI 对话智能体

- **LangGraph 多专家对话**：需求分析、任务规划、工具调用
