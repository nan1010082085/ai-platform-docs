# 用户与租户管理 · 更新日志

> 记录 UA（用户与租户管理台）的主要迭代。

## 2026-09-05 · 租户重设计 P1–P6 落地 + 限额 + 邀请码

- **租户体系**：平台默认业务 ID 固定 `000000`；`tenantCode=default`；chat/forum 应用租户；Membership / Invite / org·join 注册
- **UA**：邀请码页、租户「平台额度」、用户额度；设备管理页
- **限额**：TenantLlmQuota / UserLlmQuota + 有效额度 API（设计 §12 / P6）
- **展示账号**：`demo` / `demo123456` @ `000000`
- **未做（P7）**：邮件邀请 SMTP + UA 发信 + `?inviteCode=` 落地 — 见设计 §13
- **开放清单**：[open-work-inventory](../design/open-work-inventory.md)

## 2026-09-05 · 租户中心化 + Chat/Forum 应用租户 + 展示用户（切片）

- **UA UI**：侧栏运营台；租户页系统/应用卡片 + 组织分区；用户列表强化租户/来源筛选
- **应用租户**：seed `chat`、`forum`；`chat` 供 **workflow-agent-chat** 登录/注册；论坛注册写入 forum；AI/Editor/Flow 走平台组织租户
- **展示用户**：seed `demo` / `demo123456`，角色「普通用户」，供验收与演示
- **计划并入**：模型中心 API 三级限额（平台→租户→用户），见设计文档 §12

## 2026-07-27 · 多租户增强

- **租户配置**：租户级模型配置、功能开关
- **租户切换**：管理员可在租户间切换
- **数据隔离**：自动 tenantId 注入，数据完全隔离

## 2026-07-22 · 权限系统完善

- **权限码扩充**：50+ 权限码，覆盖菜单、操作、数据三个维度
- **角色继承**：角色支持继承，减少重复配置
- **数据权限**：行级数据权限控制

## 2026-07-15 · SSO 集成

- **SSO 客户端管理**：创建、编辑、删除 SSO 客户端
- **单点登录**：支持 SAML 2.0 / OAuth 2.0
- **会话管理**：统一会话、单点登出

## 2026-07-10 · 模型配置

- **AI 模型管理**：DeepSeek / OpenAI / Anthropic 模型配置
- **Provider 配置**：自定义 Provider、API Key 管理
- **模型测试**：在线测试模型连接

## 2026-07-05 · 用户与角色管理

- **用户 CRUD**：用户列表、创建、编辑、删除
- **角色管理**：角色定义、权限分配
- **菜单管理**：动态菜单、权限菜单
