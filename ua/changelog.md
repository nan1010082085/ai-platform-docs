# 用户与租户管理 · 更新日志

> 记录 UA（用户与租户管理台）的主要迭代。

## 2026-07-27 · 多租户增强

- **租户配置**：租户级模型配置、功能开关
- **租户切换**：管理员可在租户间切换
- **数据隔离**：自动 tenantId 注入，数据完全隔离

## 2026-07-22 · 权限系统完善

- **权限码扩充**：50+ 权限码，覆盖菜单、操作、数据三个维度
- **角色继承**：角色支持继承，减少重复配置
- **数据权限**：行级数据权限控制

## 2026-07-15 · SSO 集成

- **SSO 客户端管理**：创建、编辑、删除 SSO 客户端
- **单点登录**：支持 SAML 2.0 / OAuth 2.0
- **会话管理**：统一会话、单点登出

## 2026-07-10 · 模型配置

- **AI 模型管理**：DeepSeek / OpenAI / Anthropic 模型配置
- **Provider 配置**：自定义 Provider、API Key 管理
- **模型测试**：在线测试模型连接

## 2026-07-05 · 用户与角色管理

- **用户 CRUD**：用户列表、创建、编辑、删除
- **角色管理**：角色定义、权限分配
- **菜单管理**：动态菜单、权限菜单

## 架构基线

| 组件 | 说明 |

| Element Plus | UI 组件库 |
| Pinia | 状态管理 |
