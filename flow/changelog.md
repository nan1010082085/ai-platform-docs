# 流程设计器 · 更新日志

> 记录流程设计器（BPMN 编排 + 实例/任务管理）的主要迭代。

## 2026-07-27 · 多智能体协同

- **流程 AI 助手**：对话式流程生成，自然语言描述自动生成 BPMN
- **子流程调用**：支持嵌套子流程，模块化流程设计
- **并行网关增强**：多分支并行执行 + 条件汇聚

## 2026-07-22 · 工作流集成

- **Workflow-as-Flow**：Agent Workflow 可作为流程节点调用
- **表单联动增强**：UserTask 表单支持动态字段、条件显隐
- **流程监控面板**：实时流程执行状态、节点耗时统计

## 2026-07-15 · 实例与任务管理

- **任务收件箱**：待办任务列表、批量操作
- **审批历史**：完整审批轨迹、意见记录
- **委托与转办**：任务委托、转办功能
- **超时自动处理**：节点超时自动通过/拒绝

## 2026-07-10 · BPMN 设计器增强

- **节点面板优化**：拖拽创建、快速配置
- **流程仿真**：设计态模拟执行、节点高亮
- **撤销/重做**：操作历史、快捷键支持
- **导入/导出**：BPMN XML 导入导出

## 2026-07-05 · FlowEngine 运行时

- **Token 模型**：流程实例 Token 驱动执行
- **条件分支**：Exclusive Gateway 条件路由
- **用户任务**：UserTask 人工审批节点
- **服务任务**：ServiceTask 自动执行节点

## 2026-06-27 · v1.0.2

- 生产环境 base 路径修正：`micro/flow/` -> `child/flow/`
- stores（flowDefinition / flowTemplate / flowMonitor）统一 useDataLoading 模式
- `.env.production` 路径同步修正
- 测试修复：383 tests 通过（+131）
