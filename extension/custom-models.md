# 自定义模型

接入你自己的模型服务或第三方兼容接口。

## 支持的接入方式

| 方式 | 适合 |
|---|---|
| Ollama | 本地开发或私有环境 |
| vLLM | 自建推理服务 |
| OpenAI 兼容接口 | 大多数第三方网关 |
| 私有 DeepSeek 网关 | 内部统一出口 |

## 配置入口

你可以在平台界面中添加模型服务，也可以通过环境变量配置。

界面方式适合：

- 快速测试
- 按用户或租户配置
- 不想重启服务

环境变量方式适合：

- 固定部署配置
- 运维统一管理
- 容器化环境

## Ollama 示例

1. 启动 Ollama。
2. 拉取模型。
3. 在平台中配置服务地址。
4. 填写模型名称。
5. 测试对话。

## vLLM 示例

1. 启动 vLLM 服务。
2. 确认它暴露 OpenAI 兼容接口。
3. 在平台中填写 Base URL。
4. 填写模型名称。
5. 测试对话。

## 常见问题

| 问题 | 检查 |
|---|---|
| 连接失败 | 服务是否启动、地址是否正确 |
| 模型不存在 | 模型名称是否和服务端一致 |
| 响应很慢 | 模型负载、网络、上下文长度 |
| 修改配置不生效 | 是否需要重启服务 |
