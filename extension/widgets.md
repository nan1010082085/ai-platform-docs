# 自定义控件

开发一个可以拖到页面里的自定义组件。

## 什么时候需要

- 需要一个特殊图表
- 需要接入内部业务组件
- 需要一个平台未提供的输入控件
- 需要封装一段复杂交互

## 控件要提供什么

| 部分 | 作用 |
|---|---|
| 组件实现 | 真正渲染到页面上的部分 |
| 注册信息 | 告诉编辑器这个控件叫什么、属于哪个分类 |
| 属性配置 | 让使用者在属性面板里调整参数 |
| 事件配置 | 让控件能和页面其他部分联动 |

## 开发步骤

1. 创建控件组件。
2. 定义控件名称、分类和默认属性。
3. 实现渲染逻辑。
4. 声明可配置属性。
5. 声明支持的事件。
6. 在编辑器中注册控件。
7. 拖入画布测试。
8. 发布页面验证运行态。

## 属性面板

推荐把属性分成三类：

| 分类 | 放什么 |
|---|---|
| 基础 | 名称、标签、默认值 |
| 样式 | 宽高、颜色、边距 |
| 行为 | 数据源、事件、联动 |

## 测试清单

- 新建页面后能从组件面板找到控件。
- 修改属性后画布立即更新。
- 保存后重新打开，配置不丢失。
- 发布后运行态表现正确。
- 和其他控件联动正常。
- 控件报错时不影响整个页面渲染。
