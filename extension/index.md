# 扩展开发

给 Schema Platform 增加自己的控件、插件、技能或模型服务。

## 你可以扩展什么

| 类型 | 适合 | 文档 |
|---|---|---|
| 自定义控件 | 页面里需要一个平台没有的组件 | [自定义控件](./widgets.md) |
| 插件 | 给助手或工作流增加专家、技能、工具或 MCP 服务 | [插件开发](./plugins.md) |
| 技能 | 让专家稳定遵循某个业务规则 | [技能开发](./skills.md) |
| 自定义模型 | 接入 Ollama、vLLM 或私有模型网关 | [自定义模型](./custom-models.md) |

## 开发前先确认

1. 这个能力是不是平台已经内置。
2. 你要扩展的是**页面表现**还是**模型能力**。
3. 这个扩展是否会访问敏感数据。
4. 是否需要对外分发。

## 分发方式

| 方式 | 适合 |
|---|---|
| 本地启用 | 只给自己或团队用 |
| 插件包 | 分发给其他部署实例 |
| MCP 远程服务 | 工具独立部署，平台只负责调用 |

## 下一步

- 如果要做页面组件，从 [自定义控件](./widgets.md) 开始。
- 如果要增强助手，从 [插件开发](./plugins.md) 开始。
- 如果要接入自己的模型，从 [自定义模型](./custom-models.md) 开始。
