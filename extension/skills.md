# 技能开发

技能是一段可以挂载到专家上的固定能力说明。

## 什么时候用技能

| 需求 | 适合 |
|---|---|
| 固定使用某种输出格式 | 适合 |
| 必须遵守某个业务规则 | 适合 |
| 需要补充领域知识 | 适合 |
| 需要调用外部系统 | 更适合工具 |
| 需要检索文档 | 更适合知识库 |

## 技能和提示词的区别

| 维度 | 技能 | 直接写在专家提示词里 |
|---|---|---|
| 复用 | 可以挂给多个专家 | 只属于一个专家 |
| 维护 | 独立文件，便于更新 | 和专家配置耦合 |
| 启停 | 可以单独启用停用 | 需要改专家配置 |

## 编写技能

```json
{
  "id": "custom.reply-style",
  "name": "中文回复规范",
  "content": "请使用简体中文回复；结论放在开头；列表不超过 5 项。",
  "enabled": true
}
```

## 挂载到专家

1. 打开专家配置。
2. 添加技能 ID。
3. 保存并启用。
4. 发起一次对话测试。

## 编写建议

- 用短句描述规则。
- 一次只表达一个约束。
- 避免和专家主提示词冲突。
- 不要把长文档塞进技能，长内容更适合知识库。
- 给技能起稳定的 ID，避免后续引用失效。

## 测试清单

- 技能启用后专家行为符合预期。
- 停用技能后行为恢复。
- 多个技能同时挂载时没有明显冲突。
