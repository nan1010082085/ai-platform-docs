# 部署

把 Schema Platform 部署到你自己的环境。

## 部署前先确认

| 问题 | 建议 |
|---|---|
| 谁使用 | 决定是否需要公网访问和权限控制 |
| 用什么模型 | 准备至少一个可用的模型 API Key 或私有模型服务 |
| 数据放哪里 | 确认数据库和文件存储方案 |
| 是否需要高可用 | 决定是否使用多实例和负载均衡 |

## 最小可用部署

最小部署包含：

- 前端应用
- 后端服务
- 数据库
- 至少一个模型服务

如果只是内部试用，可以使用单机 Docker Compose。

## 生产部署建议

- 使用独立域名和 HTTPS。
- 不要把敏感配置写死在代码里。
- 定期备份数据库。
- 配置日志和监控。
- 为模型服务设置用量上限。
