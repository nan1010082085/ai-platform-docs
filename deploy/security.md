# 安全

保护用户数据、模型密钥和外部调用凭证。

## 必须做的事

1. 使用 HTTPS。
2. 为生产环境生成独立密钥。
3. 不要把 API Key 写死在代码里。
4. 为外部系统分配独立 Key。
5. 定期轮换密钥。
6. 为管理页面配置访问权限。

## 密钥管理

| 密钥 | 用途 |
|---|---|
| `JWT_SECRET` | 登录态签名 |
| `CREDENTIAL_SECRET` | 凭证加密 |
| 模型 API Key | 调用模型服务 |
| 工作流 Key | 外部系统调用单个工作流 |
| 用户 API Key | 外部系统调用多个工作流 |

## 页面与 API 权限

- 只把必要页面开放给对应角色。
- 对外 API 使用独立密钥，不要复用登录态。
- 回调接口必须验签。
- 嵌入页面时限制允许的来源。

## 模型安全

| 风险 | 建议 |
|---|---|
| 数据泄露 | 只把必要数据传给模型 |
| 成本失控 | 设置用量和频率限制 |
| 越权操作 | 工具内部再做一次权限校验 |
| 无限等待 | 设置超时和重试 |

## 泄露后的处理

1. 立即让旧密钥失效。
2. 生成新密钥。
3. 更新受影响系统。
4. 检查调用日志。
5. 评估是否有数据泄露。
