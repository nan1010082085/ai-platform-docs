# 可视化编辑器 · 更新日志

> 记录编辑器（表单 / 页面 / 大屏设计器）的主要功能更新。

## 2026-08-03 · Grid 布局引擎

### 布局模式

- 布局模式命名：`free`（自由布局）与 `grid`（栅格布局）
- 创建时选定布局后不可切换；旧数据中的 `flex` 加载时自动映射为 `grid`
- 状态栏按 `schemaType` 显示表单 / 页面类型

### Grid 引擎

- 多列自适应、跨列 `gridSpan`、行列间距与列宽约束
- 画布与控件属性面板可配置 grid 参数
- 容器控件同时支持自由布局与栅格布局（`row-container` 为栅格专属）

## 2026-07-20 · 大屏与发布体验

- **大屏地基**：视口剔除、撤销/重做、大屏 Demo、主题预设
- **发布态模式**：只读 / 交互 URL 参数切换
- **快捷键与埋点**：常用编辑快捷键；前端埋点客户端
- **属性面板拆分**：按配置域拆分，维护更清晰
- **开放扩展**：SchemaType 注册式 + `createWidgetPlugin` + 第三方控件指南
