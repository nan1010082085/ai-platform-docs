# Server

`@server` - Koa.js + MongoDB backend service. Detail pages are currently in Chinese.

## Quick Start

```bash
# Local development (requires Docker MongoDB)
pnpm db:up
pnpm dev

# Seed data
pnpm db:seed

# Build
pnpm build
```
