# Property Panel

The right-side property config panel, schema-driven.

## Config Structure

Each widget's `config.ts` defines `propertyPanel`:

```ts
propertyPanel: {
  basic: ['label'],        // basic props (inherited from common panel)
  style: [],               // style props (inherited from common panel)
  props: [                 // component-specific props
    {
      key: 'placeholder',       // prop path (supports 'a.b.c' nesting)
      label: 'Placeholder',     // panel display label
      type: 'input',            // control type
      default: 'Enter...',      // default value
      placeholder: 'Hint text', // control placeholder
      visibleOn: "props.clearable === true",  // conditional visible expression
    },
  ],
}
```

## Supported Control Types

| type | Description | Extra config |
|------|------|----------|
| `input` | Text input | placeholder |
| `number` | Number input | min, max, step |
| `switch` | Switch | - |
| `select` | Dropdown | options: `{ label, value }[]` |
| `color` | Color picker | - |
| `slider` | Slider | min, max, step |
| `columns` | Table column config | - |
| `remote-select` | Remote dropdown | remoteUrl, labelField, valueField |
| `json` | JSON editor | - |

## Common Property Panel

Properties shared by all widgets (`publicStylePanel`):

- margin, padding
- backgroundColor, border, borderRadius
- fontSize, fontWeight, color, textAlign

## Conditional Visibility

`visibleOn` supports expression strings computed from the current widget's props:

```ts
visibleOn: "props.contentMode === 'microapp'"
visibleOn: "props.pagination.enabled === true"
```

## Position Properties

All widgets have a position property panel (auto-generated by PropertyPanel):

- X / Y - horizontal/vertical position
- Width / Height
- z-index
