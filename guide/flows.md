# 流程设计

用可视化流程设计器编排审批和自动化任务。

## 适合做什么

- 请假、采购、报销等审批流
- 订单、工单、合同等业务流转
- 需要人工确认的自动化流程
- 跨部门的并行审批
- 包含子流程的复杂业务

## 创建一个流程

1. 进入流程设计器。
2. 新建流程。
3. 从节点面板拖入开始节点、任务节点、网关和结束节点。
4. 连接节点，形成执行路径。
5. 点击任务节点，配置处理人、表单、超时和驳回规则。
6. 点击网关，配置条件表达式。
7. 保存并发布。

## 审批人怎么配

| 方式 | 适用场景 |
|---|---|
| 指定用户 | 固定由某个人处理 |
| 指定角色 | 由某个角色中的人处理 |
| 表达式 | 根据表单字段或组织关系动态计算 |

## 常用审批操作

| 操作 | 说明 |
|---|---|
| 通过 | 当前节点完成，流程进入下一步 |
| 驳回 | 退回指定节点，可要求发起人修改 |
| 转办 | 把任务交给其他人 |
| 委派 | 临时委托他人处理，处理结果回到原处理人 |
| 催办 | 提醒当前处理人尽快处理 |
| 撤回 | 发起人在流程进入下一节点前撤回 |

## 任务收件箱

流程发布后，处理人可以在任务收件箱中看到：

- 待办任务
- 已办任务
- 批量审批
- 审批历史
