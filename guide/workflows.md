# 智能体工作流

把一次性的对话能力，变成可反复执行的自动化流程。

## 适合做什么

- 文档解析和摘要
- 合同或票据信息抽取
- 知识库问答
- 自动生成行动建议
- 需要人工确认的业务处理
- 定时或由外部系统触发的处理任务

## 创建一个工作流

1. 进入智能体工作流设计器。
2. 新建工作流，或从模板开始。
3. 拖入节点：
   - 触发器
   - 模型调用
   - 文档解析
   - 知识检索
   - 条件判断
   - 人工确认
   - 结束节点
4. 连接节点。
5. 配置每个节点的输入和输出。
6. 保存草稿。
7. 测试运行。
8. 确认无误后发布。

## 触发方式

| 触发方式 | 适用场景 |
|---|---|
| 手动触发 | 临时执行或调试 |
| API 触发 | 外部系统调用 |
| Webhook 触发 | 第三方系统在事件发生时通知平台 |
| 对话触发 | 在 AI 助手中选择某个工作流执行 |

## 人工确认

如果工作流中包含人工确认节点，执行会进入等待状态。

你可以：

1. 在执行详情中查看待确认内容。
2. 补充必要信息。
3. 让流程继续执行。

## 监控执行

在工作流列表中可以查看：

| 信息 | 说明 |
|---|---|
| 状态 | 运行中、成功、失败、等待人工确认 |
| 节点记录 | 每个节点的输入、输出和耗时 |
| 错误信息 | 失败节点和原因 |
| 执行历史 | 同一工作流的历次执行结果 |
