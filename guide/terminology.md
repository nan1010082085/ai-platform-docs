# 术语对照

为了让中文文档更好读，这里统一了常用词的写法。

## 产品术语

| 英文 | 中文 | 说明 |
|---|---|---|
| Agent | 智能体 | 能理解需求并执行任务的助手 |
| Workflow | 工作流 | 一组可重复执行的自动化步骤 |
| Form | 表单 | 用来收集信息的页面 |
| Page | 页面 | 发布后的可视化产物 |
| Widget | 控件 | 页面里的一个组件 |
| Plugin | 插件 | 给平台增加能力的扩展包 |
| Skill | 技能 | 挂在智能体上的固定能力说明 |
| Expert | 专家 | 擅长某一类任务的智能体角色 |
| Tool | 工具 | 智能体可以调用的具体操作 |
| Knowledge Base | 知识库 | 用来给智能体提供上下文的文档集合 |
| Evaluation | 评测 | 用数据集检验智能体效果 |

## 技术名词

这些词在正文里保留英文，首次出现时会加中文说明。

| 英文 | 中文说明 |
|---|---|
| API | 应用编程接口 |
| RAG | 检索增强生成 |
| MCP | 模型上下文协议 |
| LLM | 大语言模型 |
| Webhook | 回调通知 |
| JWT | 登录态令牌 |

## 写法约定

- 产品能力用中文表达。
- 代码、路径、命令和 JSON 字段保持英文。
- 不在用户文档里展开内部实现名词。
- 需要举例时，优先用业务场景，不优先用技术栈。

## 示例

| 场景 | 推荐写法 |
|---|---|
| 页面标题 | 智能体工作流 |
| 正文说明 | 用智能体工作流自动化处理文档 |
| 代码示例 | `POST /api/ai/workflows/invoke/{slug}` |
