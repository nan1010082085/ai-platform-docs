# 核心业务总览

Schema Platform 是**表单 / 流程垂直场景的 AI 应用平台**。

核心业务闭环是：

```text
定义业务表单
  ↓
编排审批 / 业务流程
  ↓
收集和管理业务数据
  ↓
分配用户 / 租户 / 权限
  ↓
用 AI 助手和智能体工作流提效
  ↓
通过 API / 嵌入方式接入现有系统
```

## 你能用它做什么

| 场景 | 能力 | 入口 |
|---|---|---|
| 定义业务表单 | 拖拽创建审批单、录入页、列表页和运营大屏 | [表单与页面](./forms.md) |
| 编排业务流程 | 可视化编排审批、自动任务、条件分支和子流程 | [流程设计](./flows.md) |
| 管理业务数据 | 查询、筛选和维护表单产生的业务数据 | [业务数据](./data.md) |
| 管理组织与权限 | 管理用户、租户、角色和数据权限 | [用户与租户](./users.md) |
| 让 AI 帮你做 | 用自然语言生成表单、流程或页面 | [AI 助手](./ai-assistant.md) |
| 自动化业务 | 把模型调用、文档解析、检索和人工确认组合成工作流 | [智能体工作流](./workflows.md) |
| 管理知识 | 上传文档并按语义检索 | [知识库](./knowledge-base.md) |
| 验证效果 | 用数据集测试工作流并对比不同版本 | [评测](./evaluation.md) |
| 扩展能力 | 安装或开发插件、控件和自定义模型 | [插件](./plugins.md) |

## 推荐路径

1. 先读 [快速开始](./quickstart.md)。
2. 如果你要搭业务表单，看 [表单与页面](./forms.md)。
3. 如果你要做审批或业务流转，看 [流程设计](./flows.md)。
4. 如果你要看表单提交后的数据，看 [业务数据](./data.md)。
5. 如果你要管账号和权限，看 [用户与租户](./users.md)。

7. 如果你要自己部署，看 [部署](../deploy/)。

## 相关概念

- **表单 / 页面**：可视化搭建后的可发布产物。
- **流程**：带审批、自动化和状态流转的业务编排。
- **业务数据**：表单和流程运行后产生的可管理记录。
- **租户**：组织或独立应用空间，用于隔离用户和业务数据。
- **智能体工作流**：可复用的自动化任务链，可由 API、Webhook 或对话触发。
- **知识库**：用于给模型提供上下文的文档集合。
- **插件**：给平台补充专家、技能、工具或外部模型能力的扩展包。
