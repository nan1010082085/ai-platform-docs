# 表单与页面

用可视化编辑器搭建可发布的页面。

## 适合做什么

- 审批表单
- 数据录入页
- 列表页和详情页
- 运营大屏
- 可嵌入第三方系统的独立页面

## 创建一个页面

1. 进入编辑器。
2. 新建页面。
3. 选择布局：
   - **普通布局**：适合表单、列表和详情页。
   - **自由布局**：适合大屏和需要精确摆放的页面。
4. 从组件面板拖入需要的组件。
5. 在右侧属性面板配置字段、样式、联动和数据源。
6. 预览确认后保存。
7. 点击发布，获取访问地址。

## 常用能力

| 能力 | 说明 |
|---|---|
| 拖拽编辑 | 直接在画布上摆放、对齐、复制和删除组件 |
| 组件联动 | 一个组件的变化可以控制另一个组件的显示、隐藏或取值 |
| 数据源 | 组件可以从 API 获取数据，也可以提交数据到后端 |
| 表单校验 | 为字段配置必填、格式和自定义规则 |
| 版本发布 | 保存草稿，发布后生成稳定访问地址 |
| 嵌入 | 发布页可通过 iframe 嵌入其他系统 |

## 发布与访问

发布后，平台会生成一个稳定地址，格式类似：

```text
/view/{pageCode}
```

常见参数：

| 参数 | 效果 |
|---|---|
| `?interaction=interactive` | 允许用户交互 |
| `?interaction=readonly` | 全局只读 |
