# 用户与租户

管理谁能进来、属于哪个组织、能做什么。

## 它解决什么问题

| 问题 | 平台能力 |
|---|---|
| 谁在使用平台 | 用户管理 |
| 不同团队如何隔离 | 租户管理 |
| 谁能做什么 | 角色与权限 |
| 数据谁能看 | 数据权限 |

## 用户管理

### 常用操作

| 操作 | 说明 |
|---|---|
| 创建用户 | 新增账号并分配租户和角色 |
| 编辑用户 | 修改基本信息或角色 |
| 重置密码 | 管理员帮助用户恢复登录 |
| 停用 / 删除 | 控制账号是否继续可用 |
| 筛选用户 | 按租户、角色或状态查找 |

## 租户管理

租户是组织或应用空间。

| 类型 | 作用 |
|---|---|
| 组织租户 | 承载一个团队或部门的业务 |
| 应用租户 | 承载一个独立应用，例如 Chat 或论坛 |
| 系统租户 | 平台内置空间，不建议随意修改 |

### 常用操作

| 操作 | 说明 |
|---|---|
| 创建租户 | 新建组织或应用空间 |
| 编辑租户 | 修改名称、状态或说明 |
| 查看租户用户 | 查看该租户下的账号 |
| 删除租户 | 删除前需要处理租户下的用户 |

## 角色与权限

| 角色 | 适合 |
|---|---|
| 超级管理员 | 平台全局管理 |
| 租户管理员 | 本租户内的用户和业务管理 |
| 普通用户 | 日常使用表单、流程和 AI 能力 |

权限通常分为：

| 权限 | 控制什么 |
|---|---|
| 功能权限 | 能进入哪些模块 |
| 操作权限 | 能新增、编辑、删除或审批 |
| 数据权限 | 能看本租户、本部门还是仅自己的数据 |

## 推荐流程

1. 先创建租户。
2. 在租户下创建用户。
3. 给用户分配角色。
4. 按业务需要配置数据权限。
5. 用户登录后开始使用对应能力。
