# 评测

用同一批数据检验工作流效果，避免“感觉可以”。

## 适合评什么

- 回答是否准确
- 抽取字段是否完整
- 是否遵守业务规则
- 是否稳定复现
- 不同版本之间谁更好

## 基本流程

1. 准备数据集。
2. 选择要评测的工作流版本。
3. 运行评测。
4. 查看每条数据的执行结果。
5. 对比不同版本。
6. 根据结果调整提示词、节点配置或知识库。

## 评测结果

| 指标 | 说明 |
|---|---|
| 通过率 | 满足预期标准的比例 |
| 耗时 | 平均执行时间 |
| Token 消耗 | 模型调用成本 |
| 失败原因 | 哪些输入导致错误 |

## 什么时候应该评测

| 时机 | 原因 |
|---|---|
| 修改提示词后 | 确认没有引入回归 |
| 更换模型后 | 比较新旧效果 |
| 更新知识库后 | 确认检索质量 |
| 发布前 | 避免把不稳定版本交给业务 |
