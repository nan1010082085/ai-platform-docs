# 插件

插件用来扩展平台能力。

## 插件能扩展什么

| 类型 | 作用 |
|---|---|
| 专家 | 让助手多一种擅长领域 |
| 技能 | 给专家补充固定能力或行为约束 |
| 工具 | 让模型可以调用一个具体操作 |
| MCP 服务 | 接入一组外部工具或资源 |
| 自定义模型 | 接入自有或第三方模型服务 |

## 使用插件

1. 进入插件中心。
2. 查看已安装插件。
3. 启用或停用插件。
4. 在助手或工作流中选择对应能力。
5. 测试效果。

## 安装第三方插件

1. 获取插件包。
2. 在插件中心导入。
3. 确认插件来源可信。
4. 启用插件。
5. 检查它申请的能力范围。
