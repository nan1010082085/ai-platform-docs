# 事件

事件用于描述对话和工作流执行过程中的状态变化。

## 对话事件

| 事件 | 含义 |
|---|---|
| 文本输出 | 助手开始或继续输出内容 |
| 思考输出 | 输出推理过程 |
| 工具调用 | 助手准备调用工具 |
| 工具结果 | 工具执行完成 |
| 专家切换 | 当前处理专家发生变化 |
| 任务链 | 多步任务开始、推进或结束 |
| 人工确认 | 助手等待用户补充信息 |
| 完成 | 本轮对话结束 |
| 错误 | 本轮对话失败 |

## 工作流事件

| 事件 | 含义 |
|---|---|
| 工作流开始 | 执行已受理 |
| 节点开始 | 某个节点开始执行 |
| 节点完成 | 某个节点执行完成 |
| 节点失败 | 某个节点执行失败 |
| 等待人工确认 | 流程暂停 |
| 继续执行 | 人工确认后恢复 |
| 工作流完成 | 全部节点执行完成 |
| 工作流失败 | 执行中断 |

## 状态说明

| 状态 | 含义 |
|---|---|
| `running` | 正在执行 |
| `waiting` | 等待人工输入 |
| `success` | 执行成功 |
| `error` | 执行失败 |
| `cancelled` | 已取消 |
