# 流程节点

业务流程由开始节点、任务节点、网关、事件和结束节点组成。

## 开始与结束

| 节点 | 作用 |
|---|---|
| 开始事件 | 流程入口 |
| 结束事件 | 流程出口 |

## 任务节点

| 节点 | 作用 |
|---|---|
| 用户任务 | 需要人工处理，例如审批或填写 |
| 服务任务 | 自动调用外部服务 |
| 脚本任务 | 执行一段脚本逻辑 |
| 发送任务 | 发送消息或通知 |
| 接收任务 | 等待外部消息 |

## 网关节点

| 节点 | 作用 |
|---|---|
| 排他网关 | 只选择一条满足条件的路径 |
| 并行网关 | 多条路径同时执行 |
| 包含网关 | 满足条件的路径都执行 |
| 事件网关 | 根据事件决定路径 |

## 事件节点

| 节点 | 作用 |
|---|---|
| 定时事件 | 到达指定时间后触发 |
| 消息事件 | 收到指定消息后触发 |
| 错误事件 | 处理流程错误 |
| 信号事件 | 收到信号后触发 |

## 子流程

| 类型 | 作用 |
|---|---|
| 内嵌子流程 | 把一段复杂逻辑包在当前流程中 |
| 调用活动 | 调用另一个已发布流程 |
