# 工作流节点

智能体工作流由不同类型的节点组成。

## 触发节点

| 节点 | 作用 |
|---|---|
| 手动触发 | 从页面或测试入口启动 |
| Webhook 触发 | 由外部系统 HTTP 请求启动 |
| 对话触发 | 在 AI 助手中选择工作流启动 |

## AI 处理节点

| 节点 | 作用 |
|---|---|
| 模型调用 | 根据提示词生成文本或结构化结果 |
| 文档解析 | 提取文档文本、分块和元数据 |
| 视觉分析 | 对图片进行描述或理解 |
| 图片生成 | 根据提示词生成图片 |
| 记忆节点 | 读取或追加对话历史 |

## 知识节点

| 节点 | 作用 |
|---|---|
| 知识检索 | 根据输入问题检索知识库 |
| 入库质检 | 检查文档内容是否适合进入知识库 |

## 逻辑节点

| 节点 | 作用 |
|---|---|
| 条件分支 | 根据表达式选择不同路径 |
| 人工确认 | 暂停流程，等待用户输入 |
| 结束节点 | 结束流程并定义输出 |

## 专家与工具节点

| 节点 | 作用 |
|---|---|
| 意图路由 | 根据用户意图选择专家 |
| 专家节点 | 调用某个已注册专家 |
| 工具节点 | 调用某个工具 |

## 变量语法

工作流节点之间可以通过变量引用上游结果。

| 变量 | 含义 |
|---|---|
| `{{$input.field}}` | 本次执行的输入字段 |
| `{{$node.nodeId.field}}` | 指定节点的输出字段 |
| `{{$json}}` | 最近一个上游节点的输出 |
| `{{$conversation}}` | 当前对话历史 |
