# 控件

页面搭建可用的组件分类。

## 表单控件

| 类型 | 作用 |
|---|---|
| 输入框 | 单行文本 |
| 文本域 | 多行文本 |
| 数字输入 | 数值 |
| 单选 / 多选 | 固定选项 |
| 下拉选择 | 从列表中选择 |
| 日期 / 时间 | 输入时间信息 |
| 文件上传 | 上传附件 |
| 图片上传 | 上传图片 |
| 级联选择 | 选择有层级关系的数据 |

## 展示控件

| 类型 | 作用 |
|---|---|
| 文本 | 展示标题、说明或静态内容 |
| 图片 | 展示图片 |
| 表格 | 展示结构化数据 |
| 图表 | 展示统计结果 |

## 布局控件

| 类型 | 作用 |
|---|---|
| 栅格 | 控制页面列数和间距 |
| 卡片 | 组织一组内容 |
| 标签页 | 分组展示内容 |
| 分隔线 | 区分区域 |

## 业务控件

| 类型 | 作用 |
|---|---|
| 列表页 | 展示和筛选数据 |
| 详情页 | 展示单条记录 |
| 审批组件 | 发起或处理审批 |
| 数据大屏组件 | 展示运营指标 |

## 通用配置

大多数控件都支持：

- 标签和名称
- 显示 / 隐藏
- 默认值
- 数据源
- 联动规则
- 事件
