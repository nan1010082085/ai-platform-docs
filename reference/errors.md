# 错误码

常见错误和排查方式。

## 工作流调用

| HTTP | code | 含义 | 处理 |
|---|---|---|---|
| `400` | `invalid_param` | 参数不合法 | 检查请求体 |
| `401` | `invalid_workflow_key` | 密钥无效 | 检查或轮换 Key |
| `404` | `workflow_not_found` | 工作流不存在或未发布 | 确认发布状态 |
| `404` | `execution_not_found` | 执行记录不存在 | 检查 executionId |
| `500` | `invoke_failed` | 平台内部错误 | 查看服务日志 |

## 模型调用

| 现象 | 可能原因 |
|---|---|
| 无响应 | 模型服务超时 |
| 鉴权失败 | API Key 错误或失效 |
| 模型不存在 | 模型名称不匹配 |
| 上下文超限 | 输入过长 |
| 余额不足 | 服务额度用尽 |

## 知识库

| 现象 | 可能原因 |
|---|---|
| 检索不到结果 | 文档未完成索引或问题不相关 |
| 索引失败 | 文件格式不支持或文件损坏 |
| 回答不准 | 知识库内容不足或检索片段不合适 |

## 页面发布

| 现象 | 可能原因 |
|---|---|
| 页面打不开 | 发布地址错误或权限不足 |
| 控件不显示 | 控件未启用或加载失败 |
| 数据不加载 | 数据源配置错误或跨域受限 |
